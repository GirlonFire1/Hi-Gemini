# Hi-Gemini: Multimodal AI Telegram Bot

A powerful Multimodal AI Assistant built for Telegram, powered by Google's Gemini Pro and Vision APIs.

## Features
- **Conversational AI:** Integrates with \gemini-pro\ to handle complex text generation and natural conversations.
- **Vision & Image Analysis:** Uses \gemini-pro-vision\ to analyze images sent by the user and provide detailed descriptions.
- **Database Integration:** Logs users to MongoDB for tracking interactions.

## Tech Stack
- Python 3
- python-telegram-bot
- Google Generative AI API (Gemini)
- MongoDB
